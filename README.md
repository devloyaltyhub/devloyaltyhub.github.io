# devloyaltyhub.github.io

Build web do Loyalty Hub Admin (Flutter) hospedado via GitHub Pages.

## Sobre

Saida estatica do build Flutter Web do painel administrativo do Loyalty Hub. Funciona como progressive web app (PWA) e serve como interface web de fallback para o admin.

## Deploy

Deploy automatico via GitHub Pages. O conteudo e o output direto de `flutter build web` do projeto `loyalty-admin-main`.
